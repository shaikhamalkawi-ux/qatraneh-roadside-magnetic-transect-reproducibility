# Zenodo archiving checklist

The GitHub repository is public and the manuscript cites an immutable source commit. Before creating the archival DOI:

1. Verify the repository commit cited in the manuscript Data Availability Statement.
2. Preserve the split-license files: MIT for software/code and CC BY 4.0 for author-owned data, documentation, and figures; third-party material retains its source terms.
3. Create or connect the Zenodo record and archive the intended GitHub source state.
4. Verify title, authors, affiliations, keywords, version, and license metadata against `CITATION.cff` and `.zenodo.json`.
5. Publish the Zenodo record only after the authors approve the deposit metadata.
6. Insert the minted DOI into the manuscript and submission metadata only after it exists; do not use a placeholder DOI.
