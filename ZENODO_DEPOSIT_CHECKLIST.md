# Zenodo / GitHub deposit checklist

The repository content and metadata files are ready. Before public release:

1. Create a new public GitHub repository and upload the contents of this directory.
2. Apply the author-approved mixed licenses in Zenodo: **MIT** for the software/code files and **CC BY 4.0** for data, documentation, and author-generated figures. Zenodo supports mixed-license uploads; retain the repository license files in the deposit.
3. Connect the GitHub repository to Zenodo, or create a manual Zenodo draft.
4. If a DOI is needed before publication, reserve it in the Zenodo draft and insert it into the manuscript Data Availability Statement and this README.
5. If using GitHub integration, note that Zenodo does not allow pre-reserving the DOI through the GitHub-release workflow; the DOI is created after the archived release. A manual Zenodo draft can reserve a DOI before publication.
6. Tag/release the repository (recommended release tag: `v1.0.0`).
7. Verify the Zenodo metadata and publish the record.
8. Record the minted DOI and GitHub URL in the manuscript before journal submission.
